## FAQ

### Is there a specified release version?

The available project metadata does not include a release number. Check the repository and the hosted build for the current revision.

### How do I obtain the newest build?

Open the [Download Latest Build](https://alexjung1958.github.io/canvasify-canvas-web-hub/) link to reach the hosted version.

### Does Canvasify work locally?

Yes. Clone the repository and open its main HTML entry point. When the browser restricts direct file access, a local HTTP server is the better option.

### Where are settings kept?

Interface behavior and settings come from the HTML project files and any assets bundled with the repository.

### The page is not loading correctly. What now?

Make sure the project files downloaded completely, inspect the browser developer console for missing assets, and try serving the directory through a local HTTP server.

### How do I report an issue?

Look at the repository issue tracker and, when you open a report, include your browser, operating system, reproduction steps, and any relevant console output.
